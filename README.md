# SHOWZ.AI Masterclass — Keynote-Onepager

Interaktiver Onepager, der die Präsentation der SHOWZ.AI Masterclass (29. Juli 2026) ersetzt.
Wird live gescrollt statt Keynote-Slides.

## Stack

- Next.js 16 (App Router, React 19, TypeScript strict)
- Tailwind CSS v4
- GSAP ScrollTrigger + Lenis Smooth Scroll
- Schibsted Grotesk (Display) · Inter (UI) · Montserrat (Labels)

## Befehle

```bash
npm install
npm run dev -- -p 3600
npm run check
```

## Präsentation

- **→ / Space / PageDown** — nächster Beat
- **← / PageUp** — vorheriger Beat
- Kapitel-Panel (Hamburger oben rechts) — Direkt zu jedem Abschnitt
- `?flat` an die URL — statische Fallback-Ansicht ohne Animationen
